# ABio

面向生物学数据分析与可视化的工具集合，各软件独立维护。

| 工具 | 功能 | 使用说明 |
|---|---|---|
| [ENRICHLAB](https://github.com/absoluteLeee/ENRICHLAB) | ORA / GSEA 富集分析及可视化 | [中文说明](https://github.com/absoluteLeee/ENRICHLAB/blob/main/使用说明.md) |
| [VENNLAB](https://github.com/absoluteLeee/VENNLAB) | 2–4 集合维恩图及交集分析 | [中文说明](https://github.com/absoluteLeee/VENNLAB/blob/main/使用说明.md) |

## 下载与运行

进入对应仓库，点击 Code → Download ZIP 并完整解压。

- ENRICHLAB：安装 64 位 Python，首次运行 setup.cmd，再运行 start.cmd；使用完运行 stop.cmd。
- VENNLAB：打开 Venn.html 或运行 start.cmd，无需 Python 或 R。

请保留完整资源文件夹。仓库不包含个人分析历史和本机运行环境。
